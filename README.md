# ComparadorCodigoDocumentacion
Herramienta que compare documentación con código y devuelva si hay funciones sin documentar
o	Usaremos forma de documentación de Java
	<Nombre de función>:
	<Parametro1>:
	<Parametro2>:
	<Parametro3>:
	…
	Returns:
o	Tareas
	Pagina web para subir archivos
•	Estilo: https://text-compare.com/es/
•	En la parte de abajo del derecho, la documentación, botón para descargar
•	En la parte de arriba saldría una advertencia con las funciones que no están documentadas y un botón a su derecha de “Añadir a Documentación”
o	Al fondo de la parte de advertencias saldría un botón “Añadir todo a Documentación”
o	Al pulsar el botón se añadiría al texto de la parte derecha el esquema de documentación adecuado
•	Botón comparar
o	Al pulsarlo guardar las funciones como clave en un json con sus Parámetros como valor y buscar coincidencias en la documentación
•	ComboBox de selección de lenguaje para detectar las funciones
	2 versiones
•	Documentación en el código
•	Documentación en otro archivo
